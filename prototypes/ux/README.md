# 拾光完整 UI/UX HTML 评审原型 v2

这是用于 M1-2 开始前完成产品、交互与视觉定稿的静态 HTML 原型。它不是正式前端工程，也不连接真实 API 或用户数据。

## 如何查看

最简单的方式是直接双击 `index.html`。

如果浏览器限制了本地脚本，进入本目录后运行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:4173/`。

## 如何评审

- 左侧目录可切换 8 个核心页面。
- 顶部可在“移动 H5”和“桌面 Web”之间切换，同一套页面和行为会响应式呈现。
- 中间产品画布支持滚动、主流程点击和关键分支操作。
- 右侧可以切换异常/空状态，并记录每一页的意见。
- 顶部“全部页面”用于快速比较信息架构和页面密度。
- 评审意见保存在当前浏览器本机，也可以导出为 JSON。

## 当前覆盖

1. Agent 首页
2. 对话与收藏结果
3. 收藏库
4. 收藏详情与地点消歧
5. 计划草稿
6. 已确认计划
7. 我的
8. 只读分享页

原型使用深圳模拟内容，完整体现收藏优先、高德地点补充、预算估算、修改/撤销与恢复、外部授权和拒绝后的替代路径、提醒单独授权、三态反馈、版本管理、记忆透明度、分享预览与失效等关键产品规则。

## v2 补充范围

- Agent 首页提供“收藏一个地点”和“帮我安排时间”两个明确任务入口；
- 收藏识别包含识别中、已收藏、待选择、待补充、已撤销和识别失败六种状态；
- M02 对话输入框使用独立底部输入坞，移动端贴近底部导航，桌面端贴近内容区底部；
- 收藏库支持深圳、广州和城市待确认，并显示参与当前计划的资格与排除原因；
- 地点消歧支持具体候选、任意分店和以上都不是，修改后返回原对话；
- 计划支持外部授权、仅用收藏、继续添加收藏、备选方案、风险、外部地点操作和 Sticky 确认；
- 确认计划不自动设置提醒，提醒、分享和长期记忆分别授权；
- 完成反馈区分已完成、部分完成和未完成；
- 已确认计划支持版本、取消、分享预览与分享关闭；
- 我的页面展示记忆来源、时间和影响记录，并支持修改、停用和删除；
- 只读分享页展示更新时间、失效时间，并以“查看路线”为主操作。

## 文件

- `index.html`：评审工作台和图标资源
- `styles.css`：完整视觉与响应式样式
- `app.js`：页面、状态和模拟交互
