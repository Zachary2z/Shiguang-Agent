# 拾光 UX/UI HTML 评审原型

这是用于产品和交互评审的静态 HTML 原型，不是正式前端工程，也不连接真实 API 或用户数据。

## 如何查看

最简单的方式是直接双击 `index.html`。

如果浏览器限制了本地脚本，进入本目录后运行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:4173/`。

## 如何评审

- 左侧目录可切换 8 个核心页面。
- 中间手机支持滚动和主流程点击。
- 右侧可以切换异常/空状态，并记录每一页的意见。
- 顶部“全部页面”用于快速比较信息架构和页面密度。
- 评审意见保存在当前浏览器本机，也可以导出为 JSON。

## 当前覆盖

1. Agent 首页
2. 对话与收藏结果
3. 收藏库
4. 收藏详情与地点消歧
5. 计划草稿
6. 已确认计划
7. 我的
8. 只读分享页

原型使用深圳模拟内容，体现收藏优先、高德地点补充、预算估算、修改/撤销、外部授权和分享失效等关键产品规则。

## 文件

- `index.html`：评审工作台和图标资源
- `styles.css`：完整视觉与响应式样式
- `app.js`：页面、状态和模拟交互
