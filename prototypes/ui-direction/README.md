# 拾光正式 UI/UX 方向评审稿

这是 M1-2 开始前用于确认正式 Web/H5 视觉方向、响应式框架和关键交互语言的独立静态评审稿。

它不会连接真实 API，不代表 M1-3 之后的业务功能已经实现，也不会替代 `prototypes/ux/` 中的低保真流程原型。

## 查看

```bash
cd prototypes/ui-direction
python3 -m http.server 4175 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4175/`。

## 当前覆盖

- Agent 首页；
- 收藏库与城市/排除状态；
- 计划草案、来源、风险和确认；
- 收藏识别、外部授权、提醒授权、反馈和分享预览组件；
- 移动端底部导航、桌面端侧边导航与上下文面板；
- 390px、响应式和 1440px 评审模式。

## 边界

- 只确认视觉与交互方向；
- 不复用旧原型的 Mock 业务状态作为正式代码；
- 不初始化 Next.js，不创建 M1-2 API/SSE Client；
- 不调用真实模型、高德、网页、对象存储或付费服务。
