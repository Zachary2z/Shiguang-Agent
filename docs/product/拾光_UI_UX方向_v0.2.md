### v0.2 视觉校准

v0.2 保留 v0.1 已确认的响应式结构和产品 UX，视觉重新以原始 UX/UI 原型为基线：

- 恢复深湾绿主输入卡、纸面细网格、浮动移动导航和轻量描边卡片；
- 恢复原型的宋体展示标题与无衬线正文比例，降低桌面欢迎标题的视觉音量；
- 使用原型的线性 SVG 图标，不再用 Unicode 符号模拟功能图标；
- 青柠只承担品牌、发送和局部状态强调，双任务入口改为安静的快捷操作；
- Agent 主输入重新成为首页视觉中心，但仍位于正常内容流，不固定在页面底部。

## 1. 设计命题

拾光不是旅游攻略、地图替代品或数据仪表盘，而是一个把私人收藏整理成真实行动的安静工作台。

页面应让用户始终看清五件事：

1. 当前使用的是自己的收藏还是外部补充；
2. 哪些事实已经确认，哪些仍有风险；
3. 系统刚刚做了什么；
4. 用户还能修改、撤销或恢复什么；
5. 下一步是否需要用户授权。

## 2. 视觉方向

### 2.1 品牌气质

- 克制、安静、可信，不制造“AI 魔法”感；
- 生活化但不做内容社区，不使用网红攻略式大图瀑布流；
- 结构清楚但不做企业仪表盘，不使用无产品含义的数字卡；
- 主要内容使用中文，英文只作为少量装饰性眉题。

### 2.2 识别性元素：拾光轨迹

用细线、节点、时间与留白表达“收藏如何被排成一次真实出发”。轨迹只用于计划、执行状态和流程阶段，不扩散成无意义装饰。

### 2.3 色彩 Token

| 名称 | 色值 | 用途 |
|---|---|---|
| 纸白 Paper | `#F7F8F5` | 页面底色 |
| 表面 Surface | `#FFFFFF` | 卡片、输入和浮层 |
| 深墨 Ink | `#18201D` | 主文字 |
| 海湾绿 Bay | `#23675F` | 已确认、链接和信息强调 |
| 深湾绿 Bay Deep | `#174A44` | 品牌区、主按钮、重要容器 |
| 青柠 Light | `#C9F26B` | 唯一高能强调、当前节点 |
| 警示黄 Warning | `#9A651C` | 待选择、待补充、待确认 |
| 风险红 Danger | `#A84438` | 失败、删除与不可恢复风险 |

青柠只用于主要发送动作、当前轨迹节点和一处品牌识别，不作为大面积背景。

### 2.4 字体与字号

- 展示标题：宋体系统栈，用于页面标题、计划主题和少量品牌表达；
- 正文与控件：无衬线系统栈；
- 时间、序号与状态码：等宽系统栈；
- 正文默认不低于 14px；
- 辅助信息默认不低于 12px；
- 只有非核心状态码允许使用 10–11px；
- 触控目标最小 44×44px。

## 3. 响应式框架

### 3.1 移动端

```text
┌────────────────────┐
│ 品牌 / 页面标题     │
├────────────────────┤
│                    │
│ 单列主任务内容      │
│                    │
├────────────────────┤
│ Agent 收藏 计划 我的│
└────────────────────┘
```

- 全屏 H5，不显示模拟手机边框；
- 底部四项导航适配 `safe-area-inset-bottom`；
- 长表单、计划确认使用底部 Sticky 操作区；
- 次级信息进入抽屉或页面内折叠区。

### 3.2 桌面端

```text
┌──────────┬────────────────────┬────────────┐
│ 主导航    │ 主任务区域          │ 上下文区域  │
│          │                    │ 按需存在    │
└──────────┴────────────────────┴────────────┘
```

- 左侧导航表达与移动端一致的四个一级入口；
- 中间区域承载当前任务；
- 右侧只放来源、风险、Agent 过程或解释，不作为永久信息垃圾桶；
- 窄桌面和平板隐藏右侧区，改为抽屉。

## 4. 页面方向

### 4.1 Agent

- 首屏明确提供“收藏一个地点”和“帮我安排时间”两种任务入口；
- 主输入支持文字、链接和截图，但提交前不猜测用户意图；
- 最近收藏承担回访价值，不展示公共推荐流；
- 识别进度使用阶段，不展示没有数据依据的百分比。

### 4.2 收藏

- 支持深圳、其他已确认城市和“城市待确认”；
- 每条收藏明确是否能参与当前深圳计划；
- 排除必须显示原因，但不删除或隐藏收藏；
- 待选择、待补充与失败使用不同状态和恢复动作；
- 地点消歧必须支持具体候选、“任意分店都可以”和“以上都不是”。

### 4.3 计划

- 时间线优先展示时间、交通、费用、来源和风险；
- “预算未设置”不能写成“预算不限”；
- 外部 Place 标记“高德补充 · 未收藏”，提供查看原因、替换、删除和加入收藏；
- 默认 1 个核心活动、最多 1 个辅助地点；额外内容只能作为明确的可选延伸；
- 计划确认使用 Sticky 操作区，并说明确认后会发生什么；
- 确认计划不自动开启提醒，不自动收藏外部地点。

### 4.4 我的、反馈与分享

- 记忆展示来源、创建时间、最后使用及影响过的计划；
- 记忆支持修改、删除和停止用于推荐；
- 完成反馈区分已完成、部分完成和未完成；
- 部分完成继续选择实际到访地点；
- 分享先展示脱敏预览，再创建可关闭、会过期的只读链接；
- 分享接收页以“查看路线”为主操作。

## 5. 共同交互语言

| 类型 | 文案结构 | 操作 |
|---|---|---|
| 已完成 | 发生了什么 + 当前结果 | 查看、继续 |
| 待选择 | 已保留什么 + 为什么不能继续 | 选择、任意分店、以上都不是 |
| 待补充 | 缺少的最少信息 | 补充一个字段、暂时保留 |
| 失败 | 哪里失败 + 什么没有发生 | 重试、换文字/截图、返回 |
| 授权 | 为什么需要 + 会使用什么 + 不会做什么 | 明确允许、拒绝、替代路径 |
| 撤销 | 已撤销什么 + 恢复时限 | 恢复 |

## 6. 动效与可访问性

- 只对 `transform` 和 `opacity` 做短动效；
- 支持 `prefers-reduced-motion`；
- 键盘焦点始终可见；
- 表单有可访问名称，复合输入使用 `focus-within`；
- 普通文本对比度目标不低于 4.5:1；
- 不禁用浏览器缩放；
- 路由使用真实链接，动作使用按钮；
- 加载、Toast 和异步状态使用礼貌播报。

## 7. M1-2 采用边界

M1-2 从本方向稿提取：

- 颜色、字体、间距、圆角、阴影和状态 Token；
- 移动端、桌面端和平板框架；
- 四项主导航；
- Button、Input、Card、Status、Sticky Action、Drawer 等基础组件；
- 加载、空状态和错误状态的共同表现；
- 可访问性与减少动画基础。

M1-2 不复制本评审稿中的固定业务数据，也不提前实现 M1-3 至 M1-8 的收藏、计划、反馈、记忆或分享功能。

## 8. 本轮待评审

1. 是否保留宋体作为正式页面标题字体；
2. 青柠强调的使用强度是否合适；
3. 桌面端三栏结构是否适合长期使用；
4. 移动端 Agent 两个任务入口是否足够清楚；
5. “拾光轨迹”是否能成为计划页的稳定识别元素。
